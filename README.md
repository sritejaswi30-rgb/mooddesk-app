# MoodDesk 🌙✨

MoodDesk is a modern aesthetic productivity dashboard that combines wallpapers, widgets, notes, weather, and wellness tracking into one cozy customizable experience.

Built for students, creators, and productivity lovers who want a beautiful digital workspace.

---

# ✨ Features

## 🖼️ Custom Wallpaper Dashboard
- Upload your own wallpapers
- Aesthetic themes
- Animated/live backgrounds
- Minimal UI
- Personalized dashboard experience

---

## ⏰ Digital Clock Widget
- Real-time clock
- Date, day, month, year
- Multiple styles:
  - Neon
  - Glassmorphism
  - Minimal
  - Retro
- Smooth animations

---

## 📝 Sticky Notes
- Create draggable notes
- Auto-save notes
- Color customization
- Pin important notes
- Clean sticky-note design

---

## ✅ To-Do List
- Add/edit/delete tasks
- Daily productivity tracking
- Task completion animations
- Streak system
- Priority labels

---

## ☁️ Weather Forecast
- Live weather updates
- Temperature
- Rain forecast
- Humidity
- Wind speed
- Sunrise/Sunset
- Location-based weather

---

## ✨ Daily Vibes Widget
A single interactive widget that combines:
- 🍀 Fortune Cookie Messages
- 🔮 Tarot Card Readings
- 🎲 Random Fun Facts

Features:
- Daily fortune messages
- Animated tarot card flip effect
- Refreshable fun facts
- Cozy aesthetic UI
- Smooth glassmorphism design
- Daily mood and positivity experience

Example:
> Fortune: “A new opportunity is closer than you think.”

> Tarot Card: “The Star — hope, inspiration, positivity.”

> Fun Fact: “Octopuses have three hearts.”

---

## 👣 Step Tracker
- Daily step counting
- Wellness tracking
- Sync with health APIs
- Walking streak tracking
- Daily movement goals
